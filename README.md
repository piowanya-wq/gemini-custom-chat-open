# Gemini Custom Chat

初作成日: 2026-07-30  
公開版作成: 2026-07-30（Codex）

Gemini APIのキー、モデルID、カスタム指示を自分のブラウザで入力して会話する、小さな静的Webアプリです。

## 使い方

1. GitHub Pages・Netlify・Cloudflare Pagesなどの静的ホスティングへ、このフォルダの中身を配置します。
2. 開いたページ右上の「設定」から、Gemini APIキー・モデルID・カスタム指示を入力します。
3. 「この端末にAPIキーを保存する」は、自分しか使わない端末でだけ有効にします。

## 大事な注意

- APIキーをこのリポジトリ、HTML、公開設定へ書き込まないでください。
- キーを保存した場合、ブラウザの `localStorage` にだけ保存されます。共有端末や他人が使う端末では保存しないでください。
- このアプリはブラウザからGemini APIへ直接接続します。より強い保護が必要なら、認証付きの自分用バックエンドを用意してください。
- 会話履歴・カスタム指示・モデル設定も、このブラウザ内に保存されます。

## 公開内容

この公開版には、個人名、人格名、会話ログ、APIキー、PC内のパスを含めません。
